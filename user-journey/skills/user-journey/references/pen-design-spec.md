## テーブルレイアウト

### フレーム構成
```
dDGxi (root: width 1662px)
├── titleArea (タイトルエリア)
├── kkrD0 (matrixArea: padding [0,24])
│   ├── headerRow (フェーズヘッダー: gap 2)
│   │   ├── rowLabel (160px)
│   │   ├── ph1 (288px, #3B82F6 認知)
│   │   ├── ph2 (288px, #8B5CF6 検討)
│   │   ├── ph3 (288px, #EAB308 初回利用)
│   │   ├── ph4 (288px, #22C55E 習慣化)
│   │   └── ph5 (288px, #F97316 推薦)
│   │
│   ├── typeBanner1 (#1F2937, ユーザータイプ名)
│   ├── actionRow1 (行動行: gap 2, height 120)
│   ├── emotionGraphRow1 (感情グラフ行: height 140)  ← NEW
│   ├── challengeRow1 (課題行: gap 2, height 120)
│   ├── oppRow1 (機会行: gap 2, height 120)
│   │
│   ├── typeBanner2
│   └── ... 繰り返し
```

### サイズ計算式
```
フレーム幅 = ラベル列幅 + (セル幅 × 5) + (gap × 6) + パディング × 2
           = 160 + (288 × 5) + (2 × 6) + (24 × 2) = 1660px → 1662px（余裕）
```

## テキスト切れ防止ルール

- セル幅 288px, パディング 12px → テキスト利用可能幅 = **264px**
- fontSize 10 / 264px → 日本語最大 **約22文字**
- 超える場合: fontSize 9 に下げる → 最大約25文字
- それでも超える場合: テキストを短縮

## 感情折れ線グラフ仕様

### 概要
各ユーザータイプの感情行を、テキストセルの代わりに折れ線グラフで表現する。
5フェーズの感情スコア（-2〜+3）を折れ線でつなぎ、各ポイントに感情ラベルを表示。

### グラフエリアのレイアウト
```
emotionGraphRow (height: 140, width: fill_container, gap: 2)
├── emotionLabel (width: 160) ← 「感情 / Emotion」ラベル
└── emotionGraph (width: fill_container, height: 140)
    ├── gridBg (背景グリッド: 薄いグレーの水平線)
    ├── baselineLine (y=0 の基準線: ダッシュ線)
    ├── dataPoint1 (circle at phase1)
    ├── dataPoint2 (circle at phase2)
    ├── ... (5ポイント)
    ├── line1-2 (ポイント1→2をつなぐ線)
    ├── line2-3
    ├── line3-4
    ├── line4-5
    ├── label1 (感情テキスト + スコア)
    ├── label2
    └── ...
```

### 座標計算

グラフエリア（emotionGraph）の内部座標:
- 幅: 約1450px（5フェーズ分）
- 高さ: 140px
- パディング: 上下16px, 左右24px
- 描画エリア: 幅1402px × 高さ108px

```
X座標（各フェーズの中央）:
  phase1_x = 24 + (1402 / 5) * 0 + (1402 / 5) / 2 = 24 + 140 = 164
  phase2_x = 24 + (1402 / 5) * 1 + (1402 / 5) / 2 = 24 + 420 = 444
  phase3_x = 24 + (1402 / 5) * 2 + (1402 / 5) / 2 = 24 + 701 = 725
  phase4_x = 24 + (1402 / 5) * 3 + (1402 / 5) / 2 = 24 + 981 = 1005
  phase5_x = 24 + (1402 / 5) * 4 + (1402 / 5) / 2 = 24 + 1262 = 1286

Y座標（スコアに対応）:
  スコア範囲: -2 〜 +3（合計5段階）
  y_top = 16 (score +3)
  y_bottom = 124 (score -2)
  y_per_score = (124 - 16) / 5 = 21.6px

  score_to_y(score) = 124 - (score + 2) * 21.6
    +3 → 16
    +2 → 37.6 ≈ 38
    +1 → 59.2 ≈ 59
     0 → 80.8 ≈ 81
    -1 → 102.4 ≈ 102
    -2 → 124
```

### データポイントのスタイル
- **ノードタイプ**: ellipse
- **サイズ**: 12px × 12px
- **fill**: 感情スコア色（上記カラーパレット参照）
- **stroke**: #FFFFFF, strokeWidth: 2
- **配置**: 中心座標 = (phase_x, score_y)

### 接続線のスタイル
- **ノードタイプ**: line
- **stroke**: #6B7280 (グレー)
- **strokeWidth**: 2
- **始点・終点**: 各データポイントの中心

### 感情ラベルのスタイル
- **ノードタイプ**: text
- **fontSize**: 10
- **fontWeight**: 600
- **配置**: データポイントの上（正スコア）または下（負スコア）に 16px オフセット
- **content**: 「{感情名}\n{スコア}」

### 基準線（y=0）
- **ノードタイプ**: line
- **stroke**: #D1D5DB
- **strokeWidth**: 1
- **strokeDasharray**: [4, 4]（点線）
- **y座標**: score_to_y(0) = 81

### グリッド線（オプション）
- スコア +2, +1, -1 の位置に薄いグレー線
- stroke: #F3F4F6, strokeWidth: 1

## セクション間スペーシング

ユーザータイプ間に視覚的な区切りを入れて視認性を確保する。

### スペーサーフレーム
各ユーザータイプセクション（バナー + 行動 + 感情グラフ + 課題 + 機会）の**後**に、次のユーザータイプセクションとの間にスペーサーフレームを挿入する。

```
構造:
  typeBanner1
  actionRow1
  emotionGraphRow1
  challengeRow1
  oppRow1
  spacer1 ← NEW（最後のユーザータイプの後には不要）
  typeBanner2
  actionRow2
  ...
```

### スペーサーの仕様
- **type**: frame
- **width**: fill_container
- **height**: 24px
- **fill**: transparent（背景なし）
- **padding**: なし
- **配置**: matrixArea の子要素として、各ユーザータイプセクションの oppRow の直後に挿入
- **最後のユーザータイプの後には挿入しない**（末尾に余白が不要なため）
