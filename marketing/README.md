# Marketing

アプリ名決定・ASO最適化・スクリーンショット作成・プレビュー動画生成

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| **app-naming** | `/app-naming` | 5つの専門エージェント（ブランディング・商標・デジタルプレゼンス・国際展開・コンテキスト管理）がチームで相互フィードバックしながら議論し、最適なアプリ名を決定する |
| **aso-optimize** [Beta] | `/aso-optimize` | 4つの専門エージェントチームで App Store / Google Play のメタデータ（タイトル・サブタイトル・キーワード・説明文・宣伝テキスト・What's New）を最適化し、最終レポートを出力する。多言語対応 |
| **screenshot-creator** [Beta] | `/screenshot-creator` | 5つの専門エージェント（クリエイティブディレクター・スクリーンショットデザイナー・コピーライター・仕様バリデーター・品質レビュアー）がチームで App Store / Google Play 用プロモーションスクリーンショットを Pencil (.pen) で生成するスキル |
| **app-store-preview-movie** [Beta] | `/app-store-preview-movie` | 5つの専門エージェント（ビデオディレクター・モーションデザイナー・スクリプトライター・プレビューレビュアー・フレームインスペクター）がチームで App Store プレビュー動画を Remotion (React) で生成・検証するスキル |
| **frame-inspect** [Beta] | `/frame-inspect` | 動画・画像のフレーム抽出、Remotion レンダリング、仕様チェック、目視検証を行う汎用ビデオツールキット。統一シェルスクリプト (video-tool.sh) で操作 |

### app-naming

5つの専門エージェント（ブランディング・商標・デジタルプレゼンス・国際展開・コンテキスト管理）がチームで相互フィードバックしながら議論し、最適なアプリ名を決定する

5つの専門エージェントがチームで相互フィードバックしながら議論し、最適なアプリ名を決定する。

```
/app-naming
```

### aso-optimize [Beta]

4つの専門エージェントチームで App Store / Google Play のメタデータ（タイトル・サブタイトル・キーワード・説明文・宣伝テキスト・What's New）を最適化し、最終レポートを出力する。多言語対応

4つの専門エージェントがチームで議論・フィードバックし合い、App Store / Google Play 向けの最適なメタデータを作成する。

```
/aso-optimize
```

### screenshot-creator [Beta]

5つの専門エージェント（クリエイティブディレクター・スクリーンショットデザイナー・コピーライター・仕様バリデーター・品質レビュアー）がチームで App Store / Google Play 用プロモーションスクリーンショットを Pencil (.pen) で生成するスキル

```
/screenshot-creator
```

### app-store-preview-movie [Beta]

5つの専門エージェント（ビデオディレクター・モーションデザイナー・スクリプトライター・プレビューレビュアー・フレームインスペクター）がチームで App Store プレビュー動画を Remotion (React) で生成・検証するスキル

```
/app-store-preview-movie
```

### frame-inspect [Beta]

動画・画像のフレーム抽出、Remotion レンダリング、仕様チェック、目視検証を行う汎用ビデオツールキット。統一シェルスクリプト (video-tool.sh) で操作

動画・画像のフレーム抽出、Remotion レンダリング、仕様チェック、目視検証の統合ツールキット。

```
/frame-inspect
```
