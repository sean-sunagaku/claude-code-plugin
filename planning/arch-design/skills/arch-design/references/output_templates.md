## 依存グラフ（テキスト表現）

テキストで依存関係を表現するフォーマット:

```
凡例:
  A → B     : A は B に依存する（ビルド時）
  A ─→ B    : A のデータが B に流れる（実行時）
  [Interface]: インターフェース（抽象）
  (Module)  : 具体的なモジュール

例:
(ViewModel) → [RepositoryProtocol] ← (SQLiteRepository)
      ↑
(View) ─→ (ViewModel) ─→ [APIProtocol] ← (NetworkRepository)
```

## モジュール一覧表テンプレート

```markdown
| モジュール | 責務 | 公開API | 依存先 | 安定度 |
|-----------|------|--------|-------|-------|
| AuthModule | ユーザー認証・セッション管理 | `AuthService`, `AuthState` | [UserRepository] | 中 |
| UserModule | ユーザー情報の表示・編集 | `UserViewModel`, `UserView` | [AuthModule], [ProfileRepository] | 低 |
| CoreModule | 共通型・ユーティリティ | `Result`, `Error`, `Logger` | なし | 高 |
```
