# 成果物テンプレート

各ステップの出力ファイルに使用するテンプレート。
Facilitator はステップ完了時にこのテンプレートに沿って成果物を生成する。

Mode A（機能壁打ち）: `1_purpose.md` 〜 `5_ui_prompt.md`
Mode B（プロダクト機能設計）: `P1_context_synthesis.md` 〜 `P5_screen_architecture.md`

---
