# モバイルアプリ向け Salt パターン集

## 基本画面構成（3層）

```plantuml
@startsalt
{+
  {#
    <&arrow-left> | **画面タイトル** | <&ellipses>
  }
  --
  メインコンテンツ
  .
  .
  ==
  {#
    <&home> ホーム | <&list> タスク | <&bell> 通知 | <&person> 設定
  }
}
@endsalt
```

---

## ナビゲーションバー

```plantuml
{#
  <&arrow-left> | **タイトル** | <&ellipses>
}
```

戻るボタンなし（ルート画面）:

```plantuml
{#
  . | **タイトル** | <&cog>
}
```

---

## リスト表示

### セパレータ区切り

```plantuml
{
  <&person> ユーザー名1 -- 説明テキスト
  --
  <&person> ユーザー名2 -- 説明テキスト
  --
  <&person> ユーザー名3 -- 説明テキスト
}
```

### 罫線区切り（詳細付き）

```plantuml
{-
  <&person> ユーザー名1 | 詳細テキスト | >
  <&person> ユーザー名2 | 詳細テキスト | >
  <&person> ユーザー名3 | 詳細テキスト | >
}
```

## カード表示

### 縦並び

```plantuml
{
  {^"タスク: 設計書作成"
    期限: 2026/03/20
    担当: 田中
    [詳細を見る]
  }
  {^"タスク: API実装"
    期限: 2026/03/25
    担当: 佐藤
    [詳細を見る]
  }
}
```

### 横並び

```plantuml
{
  {^"カード1"
    内容A
    [アクション]
  } | {^"カード2"
    内容B
    [アクション]
  }
}
```

## フォーム

```plantuml
{+
  {#
    <&arrow-left> | **タスク作成** | .
  }
  --
  {
    タスク名
    "                              "
    ..
    説明
    {SI
      "                            "
      "                            "
      "                            "
    }
    ..
    優先度
    ^中^高^中^低^
    ..
    期限
    "2026/03/20"
    ..
    担当者
    ^田中^田中^佐藤^鈴木^
    ..
    ラベル
    [X] バグ
    [ ] 機能追加
    [ ] 改善
    --
    [        保存        ]
  }
}
```

## カンバンボード

```plantuml
@startsalt
{+
  {#
    <&arrow-left> | **カンバン** | <&plus>
  }
  --
  {
    {^"TODO"
      {^"タスク1"
        期限: 03/20
        <&person> 田中
      }
      {^"タスク2"
        期限: 03/22
        <&person> 佐藤
      }
    } | {^"進行中"
      {^"タスク3"
        期限: 03/18
        <&person> 鈴木
      }
    } | {^"完了"
      {^"タスク4"
        期限: 03/15
        <&person> 田中
      }
    }
  }
  ==
  {#
    <&home> ホーム | <&list> タスク | <&bell> 通知 | <&person> 設定
  }
}
@endsalt
```

## タイマー画面（ポモドーロ等）

```plantuml
@startsalt
{+
  {#
    . | **集中タイマー** | <&cog>
  }
  --
  {
    .
    .
    <size:32>**25:00**</size>
    .
    集中フェーズ
    .
    .
    --
    [  開始  ] | [リセット]
    ..
    今日の記録: 3 / 8 ポモドーロ
  }
  ==
  {#
    <&clock> タイマー | <&list> 履歴 | <&cog> 設定
  }
}
@endsalt
```
