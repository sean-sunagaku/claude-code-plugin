# LT iOS Launch

Use `lt-sprint-orchestrator` as the clock and completion contract.

Delegate each bounded phase to the matching skill:

1. `product-sparring-lite`
2. `ios-design-handoff`
3. `launch-lp-lite` and `aso-copy-lite`
4. `simulator-screenshots` and `promo-video-lite`
5. `ios-privacy-scan`

Run the app implementation and build between phases 2 and 4. Keep the three-screen,
local-only scope frozen. Report every fallback and complete all artifacts required by
`lt-sprint-orchestrator`.
