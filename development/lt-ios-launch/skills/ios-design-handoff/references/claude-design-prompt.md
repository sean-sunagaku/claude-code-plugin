# Claude Design prompt

Create a polished, interactive native-iOS prototype for the attached frozen requirements.

Use exactly three app screens: Home, Play, and Result. Use the “quiet examination room” direction: off-white background, dark ink typography, generous space, and color tiles as the visual hero. Keep it friendly and focused, not clinical or sterile.

Requirements:

- iPhone 17 Pro–class 393 × 852 pt viewport with safe areas.
- Native iOS hierarchy, SF Pro, 8 pt spacing rhythm, and 44 pt minimum touch targets.
- Functional navigation: Home → Play → Result; Result → Retry or Home.
- Functional Play state with one subtly different tile, correct and incorrect feedback, countdown, level, and penalty.
- Important feedback must use symbol, motion/haptic intent, or text in addition to color.
- Support Dynamic Type, Reduce Motion, light/dark appearance, and VoiceOver labels.
- No login, network, external API, payment, remote asset, or third-party UI library.
- Include a compact screen-flow/storyboard view and implementation notes.
- Keep all motion reproducible in basic SwiftUI.

Name the project “いろちがい — iOS UI & Handoff”. Do not add screens or settings.
