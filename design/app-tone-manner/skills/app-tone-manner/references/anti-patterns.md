# AIっぽいデザインのアンチパターン集

トーン&マナー設計で絶対に避けるべきパターン。
特に color-expert, typography-director, visual-style-architect はこのリストを常に参照し、
自分の提案がアンチパターンに該当していないか確認すること。

---

## 1. フォントのアンチパターン

### 禁止フォント（単独使用・組み合わせ共に）

以下のフォントは「SaaS テンプレート感」「AI 生成感」を強く想起させるため、メインフォントとしての採用を禁止する。

| フォント | 理由 |
|---------|------|
| Inter | 最も使われすぎた AI/SaaS デフォルト。個性ゼロ |
| Roboto | Android デフォルト。プラットフォーム感が強すぎる |
| Arial | OS デフォルト。ジェネリックの代名詞 |
| system-ui | フォント選定を放棄したデザイン |
| Space Grotesk | AI スタートアップで過度に使用 |

### 禁止組み合わせ

| 組み合わせ | 理由 |
|-----------|------|
| Inter + Inter | Display と Body が同一 = 階層なし |
| Roboto + Open Sans | 「とりあえず Google Fonts」感 |
| 任意のジェネリックサンセリフ × 2 | 対比不足、個性なし |

### 代替選定の考え方

- **Display フォント**: キャラクターの強いセリフ体（Playfair Display, DM Serif Text, Fraunces）、ユニークなサンセリフ（Satoshi, General Sans, Cabinet Grotesk）、幾何学的ディスプレイ（Clash Display, Syne）
- **Body フォント**: Display との対比を意識。可読性と個性のバランス（Söhne, Switzer, Plus Jakarta Sans, Outfit）
- **日本語フォント**: Noto Sans JP 以外も検討（BIZ UDPGothic, LINE Seed JP, M PLUS Rounded, Zen Kaku Gothic New）
- **ペアリング原則**: 厳格×柔軟、幾何学×オーガニック — 対比が重要

## 2. カラーのアンチパターン

### 禁止カラーパターン

| パターン | 理由 | 代替アプローチ |
|---------|------|-------------|
| 紫→青グラデーション + 白背景 | AI スタートアップの最頻出パターン | 単色ドミナント + シャープなアクセント |
| 無難な青一色 (#3B82F6 等) | 企業サイトのデフォルト感 | 偏った色温度で個性を出す（ティール、インディゴ等） |
| 等分配カラーパレット | コントラストが生まれない | 60-30-10 ルールでドミナントを明確に |
| 真っ白背景 (#FFFFFF) のみ | 没個性 | クリーム (#FFFBF0)、ウォームグレー (#F5F3EF)、濃紺 (#0A1628) |
| レインボーグラデーション | AI アート風。ブランドの焦点がない | 2-3色に絞った意図的な配色 |
| 高彩度の多色使い | ごちゃごちゃして安っぽい | 彩度を揃え、アクセントは1色に絞る |

### 避けるべきカラーの使い方

| やりがち | 代替 |
|---------|------|
| Primary = Blue (#3B82F6) | ブランドアーキタイプから導出した固有色 |
| Success = #22C55E (Tailwind green-500) | ブランドカラーに合わせた固有のセマンティック色 |
| テキスト = #000000 | 環境に合わせた微調整（#0F172A, #1A1A2E 等） |
| ダークモード = 全色反転 | redesigned: 各色をダーク環境用に再設計 |

### カラー選定の正しいアプローチ

1. **トーン先行**: 彩度・明度の方向性を先に決める
2. **ドミナント + アクセント**: 1つの支配色 + 1つのシャープなアクセント
3. **背景色の意図**: 白以外の選択肢を必ず検討する
4. **文化コンテキスト**: ターゲット市場の色彩心理を考慮
5. **WCAG 必達**: AA 以上のコントラスト比を全テキストで確保

## 3. レイアウトのアンチパターン

### 禁止レイアウトパターン

| パターン | 理由 | 代替 |
|---------|------|------|
| Hero + Card Grid + CTA の3セクション | 予測可能すぎる（AI 生成の典型） | 非対称レイアウト、グリッド破り要素 |
| 左テキスト + 右イメージの繰り返し | 単調。AI が「安全」と判断する配置 | 対角線の流れ、重なり、非対称配置 |
| 等間隔の余白配置 | リズムがない（機械的） | 意図的な余白の強弱（タイトvsルーズ） |
| 全セクション中央揃え | 没個性、弱い印象 | 左揃え基調 + 意図的な中央揃えポイント |
| カード = 白背景 + 薄い影 + 角丸8px | Material Design のデフォルト感 | ブランドに合わせた独自のカードスタイル |

### 避けるべき UI コンポーネント処理

| やりがち | 代替 |
|---------|------|
| ボタン = 角丸8px + 青系 | デザインテンションに基づく固有スタイル |
| アイコン = Heroicons そのまま | ストローク幅・サイズをブランドに合わせて調整 |
| 影 = `shadow-md` 一律 | エレベーションシステムを設計して適用 |
| ホバー = opacity 変化のみ | ブランドに合ったインタラクション（色変化、微移動、スケール） |

## 4. モーション/アニメーションのアンチパターン

| パターン | 理由 | 代替 |
|---------|------|------|
| 全要素 fade-in | 退屈、AI テンプレートの特徴 | 要素の役割に応じた固有アニメーション |
| 一律 300ms ease-in-out | 「設計していない」感 | 要素の重要度でタイミングを変える |
| パララックス乱用 | 2015年感、パフォーマンス問題 | 控えめで意図的なスクロール連動 |
| ローディングスピナーのみ | 退屈 | スケルトンスクリーン、プログレス表示 |

## 5. イラスト/画像のアンチパターン

| パターン | 理由 | 代替 |
|---------|------|------|
| unDraw / Humaaans 系イラスト | AI/SaaS テンプレートの象徴 | ブランド固有のイラストスタイル |
| ストックフォト風画像 | 没個性、不自然 | ブランドの写真スタイルを定義 |
| 抽象的な幾何学パターン背景 | AI アート感 | 意図的なテクスチャ（ノイズ、グレイン等） |
| グラデーションメッシュ背景の乱用 | AI 生成感が強い | 単色 or 微妙なテクスチャ |

## 6. トーン・オブ・ボイスのアンチパターン

| パターン | 理由 | 代替 |
|---------|------|------|
| 「シンプル・直感的・パワフル」の3点セット | 全 SaaS が使う空虚な形容詞 | ブランドアーキタイプに基づく固有の表現 |
| 全てのボタンが「Get Started」 | ジェネリック | アクションに応じた具体的なラベル |
| エラーメッセージ = 「問題が発生しました」 | 不親切 | 何が起きたか + 何をすべきかを具体的に |
| 過度な「！」の使用 | 安っぽい | 句読点で感情を表現しない |
| 「AI が〜してくれます」表現 | AI ツール感 | ユーザーの行動主体で表現 |

## 7. 全体的な判断基準

### "What's the one thing someone will remember?"

UNFORGETTABLE な要素は1つに絞る。複数の主張は互いに打ち消し合う。

### チェックリスト（全提案に対して実施）

- [ ] デザインテンション（矛盾ペア）が全ての判断に反映されている
- [ ] 上記アンチパターンのいずれにも該当していない
- [ ] 競合3社と並べた時に明確に識別できる
- [ ] ターゲットペルソナの年齢層・文化コンテキストに適している
- [ ] 「AIっぽい」と感じる要素が1つもない
- [ ] 「この1つだけ覚えてもらいたい」ビジュアル要素が定義されている

### 判断に迷った時のルール

1. **安全な選択肢は却下**: 「無難」「よくある」「定番」はアンチパターン
2. **デザインテンションに立ち返る**: 矛盾ペアのどちらの方向に倒すべきかで判断
3. **ペルソナに聞く**: 「このターゲットユーザーは、これを見てどう感じるか？」
4. **競合と比較**: 「競合のサイトと並べて、区別がつくか？」
5. **1つに絞る**: 複数の主張が競合する時は、最も記憶に残る1つを選ぶ
