# ペルソナプロファイル テンプレート

persona-writer はこのテンプレートに沿ってペルソナを執筆する。
プロダクトに応じてセクション内容を適宜調整すること。

## テンプレート

```markdown
# Persona {NN}: {名前}（{セグメント名}）

> "{ペルソナの声を代表する一言}"

---

## 基本属性

| 属性 | 内容 |
|------|------|
| 名前 | {フルネーム（読み仮名）} |
| 年齢 | {年齢} |
| 性別 | {性別} |
| 居住地 | {都道府県・都市名} |
| 職業・雇用形態 | {会社種別} {雇用形態}（{部門}・{年数}目） |
| 年収 | {金額} |
| 家族構成 | {詳細} |

---

## 心理・行動属性

### 直面している課題
{今まさに抱えている課題・悩みの具体的内容を2〜3段落で}

### 意思決定スタイル
**{タイプ}**。{具体的な判断パターンの描写}

### 不安・恐れ
- {具体的な不安 1}
- {具体的な不安 2}
- {具体的な不安 3}

### 情報収集チャネル
- {チャネル1（具体的なサービス名と利用方法）}
- {チャネル2}
- {チャネル3}

### デジタルリテラシー
**{高/中/低}**。{具体的な利用状況の描写}

---

## プロダクト関連属性

### 利用シーン
{いつ・どこで・なぜ使うかの具体的シーン}

### 利用頻度・パターン
**{頻度}**。{利用の流れとタイミング}

### 課金意向
**{無料のみ/条件付き課金/即課金}**。{課金の判断基準}

### 期待する価値
- {具体的な価値 1}
- {具体的な価値 2}
- {具体的な価値 3}

### 離脱リスク要因
- {具体的なリスク 1}
- {具体的なリスク 2}

### 代替手段（現在のツールスタック）
{現在使っているツール/サービスの組み合わせと月額コスト}

### 乗り換えシナリオ
{きっかけ → 初日 → 3日目 → 1週間の時間軸で、現在のツールからプロダクトに乗り換えるプロセスを描写}

### 無料→有料の転換点
- **転換トリガー**: {何が起きたら課金を決断するか}
- **価格感度**: {現在のAI/SaaS支出との比較、価格に対する心理的ハードル}
- **フリーミアム示唆**: {無料プランで何を体験させれば課金に繋がるか}

---

## ナラティブ属性

### ストーリー
{この人物の背景と、プロダクトに出会う文脈を1〜2段落の物語で}

### 1日のタイムライン

| 時間 | 行動 |
|------|------|
| {時刻} | {行動（プロダクト利用シーンは**太字**で強調）} |
| ... | ... |

### プロダクトとの出会い
{どこで・何がきっかけでプロダクトを知ったか}

### 初回利用シナリオ
{最初に使ったときの内容と反応}

### 利用後の変化
{プロダクトを使って何が変わったか。具体的な行動変容}

### 引用（ペルソナの声）
"{このペルソナを象徴する一言}"
```

## 執筆ガイドライン

1. **具体的な名前を使う**: 「30代女性」ではなく「田中美咲（34歳）」
2. **物語を添える**: データだけでなく、共感できるストーリーを書く
3. **リアリティを追求**: 年齢・職業・収入・行動の組み合わせが矛盾しないこと
4. **ステレオタイプを避ける**: 個人としての独自性を描く
5. **データに基づく**: user-researcher のリサーチ結果を反映する
6. **引用符の一言**: ペルソナの本質を捉える短いセリフを添える
7. **思考プロセスを意識**: なぜこの設定にしたか、他に検討した案はあるか
8. **乗り換えシナリオを具体的に**: 意思決定スタイル（即決型/慎重型/相談必要型）に合わせて描写する
9. **無料→有料の転換点をペルソナの性格に合わせる**: 価格感度・現在の支出・家庭状況を反映する
